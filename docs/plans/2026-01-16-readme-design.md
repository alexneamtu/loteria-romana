# README Design

**Goal:** Provide a comprehensive, honest README that explains scope, data flow, current status, and roadmap for the Joker-only pipeline.

**Audience:** Users who want weekly Joker picks plus developers who want to run or extend the pipeline.

**Structure (Option A - Product + Research):**
- Overview and scope (Joker only, loto.ro only)
- What this is / isn't (explicit limits and ethics)
- Current status vs. roadmap
- Data source and pipeline flow
- Strategies (random, frequency, neural baseline)
- Quickstart and tests
- Repository layout

**Tone:** Clear, practical, and honest about limitations. No promises of higher odds.
